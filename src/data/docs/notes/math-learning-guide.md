## 从自己正在学的内容开始

先在「数学资料」目录中选择学习阶段，再用知识点、题型或方法搜索。每个专题都有独立题目入口；已有解析会另列。先完成题目、记录卡住的步骤，再对照解析比较方法。

这批资料的难度与前置知识是编辑建议，不是原 PDF 的官方分级。竞赛合集同时包含高考材料题与大学背景拓展，按自己的基础选择，不必按文件顺序全部学习。

## 初中数学

基础路线：代数式化简与方程 → 函数图象 → 三角形全等与勾股 → 相似与旋转 → 圆与几何最值。

综合路线：反比例函数的几何意义 → 动点与函数图象 → 二次函数与图形 → 手拉手、半角、三垂直 → 隐圆 → 线段最值。阿氏圆、胡不归与费马点适合在基础证明方法熟练后学习。

几何复盘时，写清“已知关系 → 辅助线或变换 → 全等/相似/圆的依据 → 目标关系”，避免只记模型名称。

## 高中专题

数列先学通项，再学求和与不等式。累加、累乘适合相邻项差或比有结构的递推；错位相减适合等差与等比乘积；分组与裂项要在式子中找到可以相消或分别求和的部分。

每次解题先判断递推结构，再选择方法。不动点是观察迭代、构造新数列和简化方程的工具，不能只背最后公式。

## 不等式与分析拓展

不等式路线：均值 → 伯努利与柯西 → 排序与代数切比雪夫 → Jensen 与幂平均 → 几何应用 → Schur。每一步都检查定义域、方向和等号条件。

分析路线：函数与导数 → 极限 → 中值定理 → 泰勒展开。帕德逼近和多元函数单列为进一步拓展。泰勒展开可以帮助猜测系数，但用来证明不等式时必须控制余项的符号。

## 组合、概率与新定义

组合题先确认计数对象和是否重复，再建立递推、双计数或对应关系。使用斐波那契等通项前统一初值与指标。

概率题先区分成功次数、首次成功时刻和不放回抽样。马尔科夫模型中，“第 n 步在哪里”与“最终能否到达”是不同问题，递推方向与边界条件也不同。

新定义题先把文字翻成量词、指标和等式，再检查最小规模的例子。保留“任意/存在”、有序对方向与分母条件，比记住定义的名字更重要。
