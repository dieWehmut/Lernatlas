# 数学资料的内容与阅读顺序

这批资料包含初中数学、高中专题和高中竞赛三个合集。网站按实际正文配对题目与解析，并以哈希合并字节相同的文件。资料编号、难度与适合年级不能只靠文件名判断。

## 初中数学

60 个专题分为代数规律、方程与不等式、函数图象、几何基础与证明、相似与变换、圆与几何最值六个方向。建议先补齐代数运算、方程、全等与勾股基础，再练习函数图象、相似和旋转，最后学习隐圆及加权最值。

具体路线可以是：反比例函数的几何意义 → 动点与函数图象 → 二次函数与图形 → 手拉手/半角/三垂直 → 隐圆 → 线段最值。每个专题先完成练习，再打开独立解析入口。

## 高中专题

34 个专题集中于数列、不动点、特殊函数及不等式。部分原目录为空，网站没有将它们标记为已有内容。

数列先从等差、等比基础进入通项，再学习求和与不等式；常用方法包括累加、累乘、待定系数、错位相减、分组与裂项。处理递推时先辨别结构，再选择变换，不把“背公式”当作识别方法的替代。

## 高中竞赛与拓展

49 个专题涉及分析与函数、不等式、数列与组合、概率统计、线性代数及集合新定义。这是混合的拓展资料集，包含高考材料题和大学背景工具，文件夹名不表示其中每项都是常规竞赛必学。

- 不等式：均值 → 伯努利/柯西 → 排序与代数切比雪夫 → Jensen 与幂平均 → 几何应用 → Schur。
- 分析与函数：函数与导数基础 → 极限 → 中值定理 → 泰勒展开；帕德逼近和多元函数单列为拓展。应用近似时检查余项和符号。
- 数列与组合：递推和组合计数 → 斐波那契/洛卡斯 → 卡塔兰 → 伯努利数及其他拓展。统一初值与编号后再使用通项。
- 概率统计：先分清成功总数、等待时间与不放回抽样；再研究状态转移。固定时刻分布用正向递推，最终吸收概率通常从当前状态反向建立递推。
- 新定义与线性代数：先把自然语言转写成量词、指标、方程或示性向量，再代入小规模例子验证。特别保留“任意/存在”、指标次序与分母条件。
