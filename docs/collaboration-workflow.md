# 分任务、分阶段提交

项目遵循：分步commit推送远程拆分多任务分步验证。

1. 从上游 Vorlage 正式导出模板，记录来源和许可。
2. 单独校验资料索引：284 个来源文件、280 个不同 PDF、143 个专题；题目与解析按正文证据配对。
3. 独立开发学习界面、模板样式、研究内容和部署工作流，各自只提交负责的文件。
4. 集成后验证 TypeScript、项目子路径构建、搜索与筛选、专题详情、PDF 阅读下载及移动端布局。
5. 全部任务完成后推送远程，跟踪 GitHub Actions 和 GitHub Pages 的实际部署状态。

本次本机协作配置已备份后调整。CLI 0.171.0 的正式配置字段为 `agents.max_concurrent_threads_per_session`；旧别名 `max_threads` 与它同时存在会触发重复字段错误。并发上限设为 TOML 整数可表示的最大值 `9223372036854775807`，并对启动配置执行严格解析检查。会话内实际可用并发量与上游服务承载能力分别由运行环境决定。

全局 AGENTS.md 保留原规则并追加用户原句。配置备份留在用户配置目录；任何凭据或本机配置正文都不进入本站仓库。
